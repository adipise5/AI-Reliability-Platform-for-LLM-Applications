# Generated OpenAPI specs

One `<service>.json` per FastAPI service, generated by importing each
service's own `app` object and calling `app.openapi()` directly — no
running server needed, so these can be regenerated offline any time a
router or schema changes:

```bash
cd services/<name>
source .venv/bin/activate
python3 -c "
import json
from <package>.api.main import app
json.dump(app.openapi(), open('../../docs/api/<name>.json', 'w'), indent=2)
"
```

These are a snapshot as of Week 16 (v1.0) — regenerate after changing any
service's routes or schemas rather than hand-editing. Every service also
serves the same spec live at `GET /openapi.json` (and interactive docs at
`GET /docs`), so these files are for offline reading/diffing, not the
source of truth.

Not included: the Dashboard Backend's `/metrics` and every other
service's `/metrics` endpoint (added in Week 16 — see
`prometheus-fastapi-instrumentator` in each `api/main.py`) don't appear
in these specs, since the instrumentator mounts them outside FastAPI's
own route registration.
